## 段階ごとの条件

### 段階 1: 第1段階：業務ルール・仕様調査と現状測定
- 対応: ACT-001;ACT-002;ACT-004;ACT-005;ACT-006;ACT-008;ACT-010;ACT-011;ACT-014
- 始める条件:
- 関係部門へ仕様照会ができ、公開サンプルのAs-Is/To-Beを参照できること
- 次へ進む条件:
- 業務ルールの決定事項と技術仕様の確認結果が設計担当に引き継げること

### 段階 2: 第2段階：個別設計
- 対応: ACT-003;ACT-007;ACT-009
- 始める条件:
- 各設計に必要な現行ルール・外部仕様の一部が確認できること
- 次へ進む条件:
- 入力検証と会計・保存設計の実装条件・試験観点がレビュー可能であること

### 段階 3: 第3段階：機能実装と単体・部分受入
- 対応: ACT-012;ACT-015;ACT-016
- 始める条件:
- 実装対象ごとの設計条件と接続権限が確認されていること
- 次へ進む条件:
- 入力・承認、会計登録、保管の各機能で正常・異常結果を記録できること

### 段階 4: 第4段階：結合受入と移行準備
- 対応: ACT-013;ACT-017
- 始める条件:
- 会計連携と保管フローの成功・失敗結果が結合試験で参照できること
- 次へ進む条件:
- 振込前の両方成功条件を含む受入結果を確認し、教育・監視・切戻し条件を整理できること
